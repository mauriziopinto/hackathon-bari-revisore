# Glossario

Termini da usare come riferimento nel controllo di qualità. Bozza ricavata dai glossari delle SD del dataset e dai termini della checklist.

## Termini dei documenti

| Termine | Definizione |
|---------|-------------|
| SD, Solution Design | Documento dei progetti waterfall che descrive la soluzione di un'iniziativa: scopo, requisiti, soluzione tecnica, impatti, piano di rollout. |
| User Story | Documento dei progetti agile. Descrive una funzione dal punto di vista di chi la usa, nella forma "Come… voglio… affinché…", con i suoi criteri di accettazione. Non dipende da una SD. |
| Requisito | Comportamento che il sistema deve avere, scritto nella tabella Requisiti della SD con un ID nella forma `REQ-nnn`. |
| Criterio di accettazione | Condizione verificabile che dice quando una User Story è realizzata correttamente. Ha un ID nella forma `CA-nn.m` e si scrive nel formato "Dato…, quando…, allora…" (può cominciare anche con Data, Dati o Date), con un esito misurabile. |
| Non conformità bloccante | Problema che da solo rende il documento non idoneo alla Knowledge Base (semaforo Rosso). |
| Non conformità non bloccante | Problema che lascia il documento idoneo con riserva (semaforo Giallo). |
| Knowledge Base (KB) | Archivio dei documenti di qualità sufficiente a essere riutilizzati. Un documento ci entra solo se non ha non conformità bloccanti. |

## Termini di dominio

| Termine | Definizione |
|---------|-------------|
| anagrafica unica | Scheda cliente univoca nel CRM, alla quale sono associati contratti, recapiti e consensi. |
| cliente business | Cliente con partita IVA, intestatario di uno o più contratti di servizio Enterprise. |
| codice fiscale | Identificativo fiscale di 16 caratteri (persona fisica) o 11 cifre (persona giuridica), verificato secondo l'algoritmo di controllo. |
| censimento | Processo di inserimento di un nuovo cliente nell'anagrafica unica. |
| storico variazioni | Registro non modificabile delle modifiche ai dati, con utente e data. |
| consenso | Manifestazione di volontà del cliente al trattamento dei propri dati per una specifica finalità. |
| finalità | Scopo del trattamento dei dati (servizio, marketing, profilazione). |
| revoca | Ritiro di un consenso o di una delega, con effetto dalla data di registrazione. |
